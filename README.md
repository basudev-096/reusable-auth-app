# Reusable Authentication App

A reusable authentication system built with **Next.js**, **Better Auth**, **Prisma**, and **PostgreSQL**.

The project provides a ready-to-use authentication foundation that can be integrated into different web applications without rebuilding the authentication system from scratch.

## Features

- User registration
- User login
- User logout
- Session-based authentication
- Protected routes
- Password-based authentication
- Secure password hashing
- Database-backed sessions
- User profile information
- Authentication state handling
- Server-side authentication checks
- Client-side authentication utilities
- Reusable authentication components
- Type-safe database access with Prisma

## Tech Stack

- **Next.js** — Full-stack React framework
- **TypeScript** — Type-safe development
- **Better Auth** — Authentication and session management
- **Prisma** — ORM and database access
- **PostgreSQL** — Relational database
- **Tailwind CSS** — Styling
- **shadcn/ui** — UI components
